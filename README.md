# Titanic Survival Prediction 🚢

A Machine Learning project that predicts whether a passenger survived the Titanic disaster using classification algorithms.

Try the deployed Streamlit application:

🔗 **Streamlit App:**  
https://your-streamlit-app-link.streamlit.app/

---

## 📌 Project Overview

The Titanic Survival Prediction project is a Binary Classification Machine Learning project.

The model predicts whether a passenger survived the Titanic disaster based on passenger details.

Prediction Output:

- `1` → Survived ✅
- `0` → Did Not Survive ❌

## 📊 Dataset Information

The project uses the Titanic dataset.

### Features:

- Passenger Class (Pclass)
- Sex
- Age
- Fare
- Number of Siblings/Spouses (SibSp)
- Number of Parents/Children (Parch)
- Embarked

### Target Variable:

- Survived

## 💻 Run Project Locally

### Clone Repository

```bash
git clone https://github.com/vaibhavkatex/Titanic-Survival.git
```

### Navigate to Project Folder

```bash
cd Titanic-Survival
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Streamlit App

```bash
streamlit run app.py
```

Open browser:

```
http://localhost:8501
```
